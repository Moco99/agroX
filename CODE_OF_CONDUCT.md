# Código de conducta

AGROX es un proyecto abierto y queremos que participar sea una buena experiencia para todas las personas, sin importar su nivel de experiencia, origen, identidad o forma de expresarse.

## Lo que esperamos

- Ser respetuoso y constructivo. Las críticas van sobre el código y las ideas, no sobre las personas.
- Asumir buena intención y explicar con paciencia, sobre todo a quien apenas empieza.
- Aceptar la crítica con apertura y dar crédito a quien contribuye.
- Citar fuentes cuando se afirma algo científico.

## Lo que no se tolera

- Acoso, insultos, amenazas o discriminación de cualquier tipo.
- Publicar información privada de otras personas.
- Spam o promoción ajena al proyecto.

## Cumplimiento

Quienes mantienen el proyecto pueden editar o eliminar comentarios, issues y PR que incumplan este código, y restringir la participación de quien lo infrinja de forma reiterada.

Para reportar una conducta inapropiada, escribe en privado a los mantenedores (por ejemplo, al propietario del repositorio en GitHub, @Moco99). Se tratará con discreción.

Este código se inspira en el [Contributor Covenant](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/) 2.1.
